# 그래픽 패널의 설정 계산

`EditorGraphicHelper`는 패널이 소유하는 C++ 비동기 설정 계산 객체이다. 도구 설정을 구하는 동작은 이미지 미리보기·픽셀 적용·문서 저장과 분리한다. `state.pending`, `valid`, `status`, `operation`, `parameters`, `error`, `sequence`는 계산 상태와 결과만 표현하며 조회 시 파일이나 픽셀을 읽지 않는다.

## 지원 계산과 입력

| 계산 | 입력 | 반환 설정 |
| --- | --- | --- |
| `samplePointColor` | 정규화 RGBA 표본 | 포인트 컬러 11개 값 |
| `sampledWhiteBalance` | RGBA 표본과 기준 화이트 밸런스 | 온도·틴트·기준 온도·기준 틴트 |
| `whiteBalancePreset` | 프리셋 열거값 | 화이트 밸런스 4개 값 |
| `autoDevelopLight` | 선택 레이어 원본 픽셀 | 노출·대비·하이라이트·그림자·화이트·블랙 |
| `autoWhiteBalance` | 원본 픽셀과 기준 화이트 밸런스 | 화이트 밸런스 4개 값 |
| `autoBlackAndWhiteMix` | 원본 픽셀 | 흑백 사용 여부와 8개 밴드 |
| `autoLensScale` | 원본 이미지와 렌즈 보정 옵션 | 스케일 |
| `estimateChromaticAberration` | 원본 픽셀 | 적색·청색 정렬값과 자동 보정 사용 여부 |

첫 세 계산은 이미지·문서 스냅샷을 캡처하지 않는다. 나머지 분석의 입력 준비와 SDK 계산은 작업 스레드에서 수행한다. 반환값을 구한 뒤 전체 보정 이미지를 다시 만들거나 결과·원본 PNG를 인코딩하지 않는다. 실제 이미지 미리보기와 픽셀 적용 API는 기존 이미지 결과 계약을 유지한다.

현재 앱은 설치된 `iiGraphicAdjust 0.4.0`을 사용한다. SDK 소스 디렉터리의 다른 버전을 앱의 실제 연결 패키지로 간주하지 않는다. 이 변경은 선택한 패키지의 기존 공개 분석 API를 사용하며 SDK 소스나 전역 설치를 바꾸지 않는다. 이 패키지의 `autoLensScale`은 유효한 ImageView를 요구하므로 해당 입력 변환도 작업 스레드에 둔다. 크기만 받는 SDK 인터페이스의 도입은 별도의 모듈 작업이다.

## 입력과 수명

작업 스레드에는 표준 C++ 값으로 파싱한 요청, 불변 프레임 스냅샷과 선택 레이어 ID 또는 기존 보정 세션의 원본 픽셀, 중지 토큰만 전달한다. 살아 있는 캔버스·QML 객체·파일 바인딩을 전달하지 않는다. 동적 레이어는 캡처한 프레임의 원본 애셋을 사용하며 합성 결과의 변환·불투명도·마스크를 분석 입력에 추가하지 않는다.

청크 이미지는 작업 스레드에서 기존 선택 픽셀 호환 영역과 같은 원점·범위로 펼친다. 이미지 분석은 기존 16Mi 픽셀 호환 범위를 지키며 픽셀이 필요 없는 계산은 큰 청크 영역에서도 가능하다. 버튼 가능 여부 조회는 애셋 종류·가시성·잠금·호환 범위만 확인하고 청크 이미지를 펼치지 않는다.

처리 중 하나와 최신 대기 요청 하나만 보유한다. 취소·문서 교체·리비전·프레임·선택·아트보드·도구·잠금·스트로크·패널 설정이나 뷰 변경은 이전 결과의 적용을 금지한다. 같은 바인딩·같은 컨텍스트·확대·이동·속성 조회는 재계산하지 않는다. 패널 종료는 작업 스레드를 기다리지 않는다. 상태를 먼저 정리한 뒤 관찰자에게 알리며 관찰자의 삭제·재시도가 새 요청을 덮지 않는다.

패널은 결과를 받을 때에도 현재 엔진과 컨텍스트를 확인한 뒤 반환값을 해당 설정에 반영한다. 계산 요청·성공·실패·취소는 문서 리비전, 저장 바이트, Alias 버전이나 파일 정보 알림을 변경하지 않는다. 큐에 넣은 실제 이미지 명령도 실행 전에 엔진·도구·뷰·설정 세대·리비전·프레임·선택·아트보드를 다시 확인한다.

## 검증과 남은 비용

`Dreamscapes.GraphicHelperValues`는 8종의 반환값을 기존 어댑터와 설치 SDK에 대조하고 입력 검증·독립 표본·취소를 검사한다. `Dreamscapes.GraphicHelper`는 작업 스레드·입력·파일 무변경·최신 요청·컨텍스트 폐기·수명·예외·청크 입력과 기존 보정 세션을 검사한다. `Dreamscapes.GraphicHelperGui`는 실제 패널의 8종 설정 반영과 대기 중 뷰·설정·대상 변경 및 큐에 있던 이미지 명령의 폐기를 검사한다.

기존 2048×2048 표본 설정 호출은 입력 준비를 제외하고 약 1.35초 동안 반환하지 않았고 PNG 문자열 두 개를 생성했다. 새 경로의 수락 시간과 작업 중 이벤트 처리는 별도로 측정한다. 수락 시간을 전체 앱 FPS나 모든 분석의 완료 시간으로 해석하지 않는다.

최초 불변 문서 스냅샷, SDK 분석 내부의 중단 지점, 실제 문서 쓰기·지속 저장과 초기화 및 전체 메서드 의미 감사는 별도 작업으로 남는다. 기존 보정 세션 원본은 공유 소유로 전달한다. 실제 패널의 이미지·마스크·인코딩 경로는 [그래픽 이미지 명령](GraphicImageCommands.md)의 C++ 작업자를 사용한다. 네이티브 전경 입력과 설치 앱 검증은 다른 UI 자동화가 종료되기 전에는 수행하지 않는다.

## 현재 프레임의 원본 일치

보조 계산이 기존 보정 원본을 재사용할 때는 도구·작업·레이어·리비전뿐 아니라 문서 세대와 현재 해석된 애셋도 확인한다. 실제 앱의 동적 레이어 선택과 미리보기·적용·Reset은 [동적 래스터 편집 계약](DynamicRasterEditing.md)을 따른다.
