# 네이티브 실패 상세 뷰 계약

생성 실패의 상세 정보는 기존 `FailureDetails.qml`의 필드 순서와 원문을 보존한다.
분석 중 안내, `details` 또는 `rawError`, 모델 미가용 사유, 에이전트 오류, 저장 오류,
보고서 경로를 순서대로 표시한다. 없는 필드는 추측하지 않는다. 표시와 복사는 생성
작업이나 보고서 파일을 변경하지 않는다.

`NativeFailureDetails.lvui`는 LVUI 모달과 읽기 전용 텍스트 뷰를 사용한다.
`FailureDetailsModel`은 원문과 문서 리비전, 열림과 오류 상태를 소유한다. 호출자는
가용 창 크기, 번역 문자열, 선택적인 클립보드 함수를 제공할 수 있다. 기본 클립보드
함수는 iiGUI를 사용한다. 텍스트 선택은 원문을 수정하지 않으며 전체 보고서 복사는
기존 선택을 바꾸지 않는다. 클립보드 쓰기와 텍스트 갱신의 실패는 화면 상태로 표시한다.
보고서 변경과 위젯 상태 변경은 소유 스레드에서만 수행해야 한다.
보고서 갱신 알림 안에서 재진입하는 갱신은 거절한다. 복사할 때는 보고서와 클립보드
함수의 스냅샷을 사용하므로 복사 중 원본이 갱신되어도 접수한 텍스트를 보존한다.

네이티브 문서와 iiGUI 기본 클립보드의 텍스트 한도는 UTF-8 기준 64 MiB이며,
NUL을 포함한 텍스트는 거절한다. 이전 1 MiB 클립보드 한도는 제거했다.
일반 길이 보고서는 LVUI `TextEditor`의 자동 줄바꿈과 내부 스크롤을 사용한다. 텍스트
레이아웃의 4096개 시각 행 예산을 어떤 폭에서도 넘지 않도록 UTF-8 바이트 수가 그보다
작은 경우에만 적용한다. 더 긴 보고서는 문서 기반 `CodeEditor`로 표시하며 아직 자동
줄바꿈하지 않는다. 원문은 잘라내지 않는다. 갱신된 LVUI 코드 편집기는 선택
범위를 64 MiB까지 조각으로 읽어 복사하지만, 이 기능을 사용하려면 해당 LVUI와 iiGUI
빌드를 함께 사용해야 한다.

기존 Qt 생성 컨트롤러와의 전환용 `NativeFailureDetailsBridge`는 백엔드 계층에 두며,
열린 작업의 보고서와 완료 알림만 네이티브 모델에 전달한다. 다른 작업의 늦은 알림은
무시하고 갱신 실패 시 기존 보고서를 보존한다. 뷰와 뷰모델은 Qt·QML·LVRS를 포함하지
않는다. 브리지는 당분간 Qt 컨트롤러의 이벤트를 사용한다.

`DreamscapesFailureDetailsNative`는 테스트 활성화와 관계없이 빌드할 수 있는 독립 뷰
라이브러리이며 `DreamscapesFailureDetailsBridge`는 기존 생성 컨트롤러가 있는 구성에서만
만든다. macOS 제품 창의 실패 상세 명령은 `NativeFailurePresenter`를 통해 실제 생성
컨트롤러와 iiGUI 임베딩 표면을 연결한다. 기존 애플리케이션의 창과 이벤트 루프는
소유자가 유지하며 투명 합성으로 모달 뒤의 창을 보존한다. 창을 닫거나 앱이 종료될 때
표면도 정리한다. 표면 장착이 실패하거나
보고서가 줄바꿈 편집기의 안전한 범위를 넘으면 기존 QML 보고서 뷰로 돌아간다.
다른 플랫폼은 아직 기존 뷰를 사용한다. 이 브리지는 전환 경계이며 앱의 다른 QML
화면이나 LVRS 의존성이 제거되었다는 뜻은 아니다.

`Dreamscapes.NativeFailureDetails`는 창 없는 iiGUI 트리에서 드래그 선택, 복사 대상,
선택 보존, 보고서 갱신과 오류, 짧은 보고서의 줄바꿈·스크롤과 긴 텍스트 대체 경로,
작은 뷰포트 및 스레드 경계를 검사한다.
모달 기하는 LVUI 값 계약을 사용하는 iiGUI 모델에서 계산하며, 줄바꿈 가능
범위는 iiGUI가 소유한 텍스트 배치와 입력 한도를 사용한다.
`Dreamscapes.NativeFailureRendererBoundary`는 생성된 뷰와 테스트 바이너리의 Qt·LVRS
의존성을 검사한다. `Dreamscapes.NativeFailureBridge`는 실제 컨트롤러의 신호에 테스트
보고서를 발행하여 해당 작업에만 반영되는지 검사한다. 실제 에이전트 실행은 포함하지
않는다. `Dreamscapes.NativeFailureClipboardMac`은 사용자의 클립보드가 아닌 고유한
macOS 페이스트보드에서 2 MiB 넘는 보고서를 실제 iiGUI 구현으로 복사·읽기 한다.
`Dreamscapes.NativeFailurePresenterMac`은 표시하지 않는 별도 AppKit 창에서 실제 생성
컨트롤러 신호, 장착·닫기·긴 보고서 복귀 및 종료 정리를 검사한다. 이는 설치된 제품의
실행 검증이나 실제 창에서의 시각적 동등성 검증과는 다르다.
