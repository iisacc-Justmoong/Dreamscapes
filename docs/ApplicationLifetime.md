# Dreamscapes 애플리케이션 수명

앱의 시작과 종료는 iiSDKCore Application과 네이티브 생명주기 객체가 소유한다.

- iiGUI 호스트는 Core 이벤트 루프에 연결되고 창이 종료되면 Core가 작업을 정리한다.
- 생성·게시·오디오 작업은 종료 요청을 받고 설정 쓰기는 완료된 뒤 리소스가 해제된다.
- 별도 비동기 종료 어댑터는 자체 조정기에 등록하며 중복 완료를 무시하고 모든 완료를 기다린다.
- 현재 네이티브 macOS 빌드의 창 닫기는 앱 종료로 이어진다. Dock 재열기 정책은 별도 검증 대상이다.

## 모델 메모리 수명

기존 생성 컨트롤러의 resident 모델 계약은 생성 작업과 추론 런타임의 수명을
구분한다. 생성 완료, 대기, 전경/배경 전환 및 메모리 경고만으로 원본을 해제하지
않도록 설계됐다. 현재 네이티브 앱의 모델 적재와 해제는 선택한 워커 및 SDK가
담당하므로 이 이력만으로 각 운영체제의 실제 재사용·종료 동작을 증명하지 않는다.
모델 원본과 사용자 파일은 생명주기 전환이나 검증 시 변경하지 않는다.

OS의 익명 메모리 압축·스왑은 허용하며 앱이 모델 볼륨에 별도 스왑 파일을 만들지
않는다. 물리 RAM 고정, 스왑 위치 변경, 강제 종료 후 메모리 복원은 제공하지 않는다.
기존 데스크탑 강제 취소/멈춤 감지의 프로세스 종료도 런타임 종료에 해당한다.
이는 백그라운드 GPU 실행 권한과 별개이며, 실행 권한이 없을 때는 기존 연산 경계
정지/재개 정책을 유지한다.

기존 Qt 생성 경로의 `Dreamscapes.Generation` 테스트는 이전 실행에서 워커 재사용을
검사했다. 당시 iOS 메모리 경고 콜백은 로그만 남기도록 작성됐다. 이 기록은 현재
네이티브 앱이나 iOS 기기에서의 동작을 검증한 결과가 아니다. OS-kill과 스왑 동작도
이번 호스트 테스트 범위에 포함되지 않는다.

기존 Qt 진입점과 생명주기 구현은 제거됐다. `NativeMain`, `NativeApplicationLifecycle`, `ApplicationShutdownCoordinator`와 iiSDKCore가 현재 경계를 구성한다. 진단 CLI의 진입점은 C++이며 기존 진단 백엔드는 Qt 데이터 타입을 계속 사용한다.

검증은 `Dreamscapes.NativeApplicationLifecycle`, `Dreamscapes.NativeApplicationRuntime`, `Dreamscapes.NativeShutdownCoordinator`와 네이티브 창 테스트 및 Qt 링크 경계 검사로 나눈다.
