# 폐기한 모델 런타임

2026-10-27부터 ONNX·ONNX Runtime을 빌드·모델 실행·설치·배포 경로에서 제거한다.
선택적 설치나 자동 다운로드 경로도 제공하지 않는다. 과거 검증 기록은 현재 지원
선언이 아니며, 해당 모델을 지원하는 것으로 간주하지 않는다.

고급 생성 UI에서 자동 Pose 선택을 제거한다. 기존 드래프트의 자동 Pose 요청은
작업을 등록하기 전에 명시적으로 거부한다. 지원되는 이미지·비디오 생성 엔진은 유지한다.
자동 테스트는 폐기한 Pose 추가·선택이 기존 드래프트와 변경 신호를 바꾸지 않는지,
지원되는 Canny·Tile 컬렉션과 프리셋이 계속 동작하는지 확인한다.
`Dreamscapes.RetiredPose`와 `Dreamscapes.AdvancedNativeControls`는 CTest의 격리된
SDK 검색 경로와 세션 복원 차단을 적용한다. 임의 셸의 SDK 환경 변수로 이전 설치본이
대신 로드된 결과를 현재 패키지의 검사로 사용해서는 안 된다.

Apple 런타임 프로필은 ONNX 링크를 거부하고, Python 작업자와 같은 격리 환경에서 설치된
네이티브 비디오 라이브러리를 직접 로드한 뒤에만 프로필을 승인한다. 라이브러리 로딩 성공은
실제 학습 모델의 비디오 생성·재생·내보내기 성공과 별도로 검증해야 한다.

iiDecision·iiLocalDiffusion·iiVoiceOver의 설치 갱신은 해당 SDK 접두사에 남은 구형
ONNX 공유 라이브러리를 제거한다. 제품 공통 배포 정책은 ONNX 런타임, 기존 Piper
바이너리와 OpenCV DNN의 재포함을 거부한다. 폐기한 모델 기능이 필요하면 지원되는
네이티브 API와 교체 가능한 iiSDK 인터페이스에 별도 구현을 연결해야 한다.
