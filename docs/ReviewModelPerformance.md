# 결과 검토의 조회와 변경 알림

결과의 메타데이터·리뷰 상태·선택·포커스는 각각 다른 변경 원인이다.
`GenerationReviewModel`은 결과 추가, 필터·정렬 변경, 현재 상태 필터에 영향을
주는 리뷰 변경에만 목록 투영을 계산한다. 단순 포커스 이동은 기존 행 인덱스로
이전·새 포커스 행의 `FocusedRole`만 알린다. 선택 변경은 정렬과 필터를 다시
실행하지 않는다.

모델은 마지막으로 공개한 행 상태를 보유하며 실제로 달라진 역할만 알린다.
인접한 행의 같은 역할 변경은 한 범위로 묶는다. 메타데이터가 같은 기존 결과에
새 결과를 덧붙일 때 기존 미리보기·메타데이터를 다시 알리지 않는다. 목록 전체
교체 시에는 Qt의 reset 계약에 따라 새 행 상태를 공개한다.

선택·후보·제외·숨겨진 선택 개수는 수락한 상태 변경에서 계산한 값을 반환한다.
getter에서 결과 전체 순회나 선택 키 벡터 할당을 수행하지 않는다. 포커스 이동은
이 개수들을 재계산하지 않는다. 전체 선택·범위 선택·일괄 리뷰는 영향을 받는
입력의 수에 비례하는 작업을 유지한다.

원본 QVariant 행, 도착 순서, 필터에 가려진 선택, 키보드 범위 선택과 리뷰 상태는
유지한다. 조회·선택·포커스에는 파일·문서·생성 API 호출을 추가하지 않는다.

`Dreamscapes.ReviewModel`은 1,000개 결과의 포커스 이동에서 알리는 행과 역할,
선택·리뷰·필터·새 결과 도착 뒤의 개수와 실제 모델 데이터를 확인한다.
`Dreamscapes.ReviewSelectionCore`는 Qt 없는 선택 정책을 별도로 검사한다.
동일 입력 1,000회의 포커스 이동·개수 조회 시간과 알린 행 수를 수정 전후
독립 프로세스에서 기록한다. 기준선과 원시 로그는
`build/optimization-20261027/`에 둔다. 이 값은 모델의 메서드·알림 범위에 대한
측정이며 설치 앱의 FPS나 실제 생성 장치 성능을 나타내지 않는다.

2026-10-27의 교대 실행 중앙값은 1,030.708ms에서 0.299084ms, 알린 행의
누적 개수는 1,000,000에서 2,000으로 줄었다. 같은 측정의 최대 RSS 중앙값은
16,416,768바이트에서 16,531,456바이트로 114,688바이트(112KiB) 증가했다.
행 인덱스와 공개 상태를 보유하는 작은 비용으로 반복 작업을 제거한 것이다.
측정에는 모델 신호 수신자와 개수 조회를 포함하며 QML 화면 그리기와 실제
모델 추론을 포함하지 않는다. 원자료는 해당 디렉터리의
`review-comparison.json`과 `review-paired-*.log`이다.

현재 구현의 회귀와 동일 입력 측정은 다음 명령으로 다시 수행할 수 있다.
시간은 기록만 하고 통과 기준으로 사용하지 않는다. 행·역할 알림, 개수, 원본
보존의 기능 단언은 반드시 만족해야 한다.

```sh
ctest --test-dir build --output-on-failure -R '^Dreamscapes\.(ReviewModel|ReviewSelectionCore|DependencyBoundary)$'
build/DreamscapesReviewModelTests focusAndCounterReadMeasurement
```

## 2026-10-27 검증 범위

macOS arm64 Release의 최종 정식 앱 빌드·배포기 서명 검증과 단일 앱 감사를
수행했다. 최종 CTest 집중 검사 8개가 모두 통과했다. 의존성 경계, 순수 선택
정책, 검토 모델, 내보내기, 실제 검토 화면, GUI 함수 등록, 정식 번들 기동,
MCP 생성·취소 연결을 포함한다. 입력 오류 해제·객체 수명·그래픽 원본 선택과
보기 옵션은 별도 연결부·화면 검사로 확인했다.

첫 전체 CTest는 126개 묶음 중 95개 통과, 31개 실패였다. 이후 발견한 입력
오류 수명, 보기 옵션, 화면 검사 연결을 수정하고 해당 경로를 재검사했다.
전체 126개가 다시 모두 통과한 결과는 아니며 색상 메뉴·타임라인 포인터,
파일 가져오기·생성·프로세스 기동 관련 실패와 시간 초과가 남아 있다.
모바일 캔버스 전환은 별도 실행에서도 `database is locked`를 재현했고,
작업자 스택에서 저장소 세션 기록의 동기화 대기를 확인했다. 이 근거만으로
공유 SDK 저장소 구현이나 내구성 설정을 변경하지 않았다.

원자료는 `build/optimization-20261027/full-ctest.xml`,
`final-focused-ctest.xml`, `verification-summary.json`에 있다. 빌드 후보는
`build/bin/Dreamscapes.app` 하나이며 버전·빌드는 모두 0.1.1이다. 설치 앱
교체와 기존 사용자 프로세스 재시작은 수행하지 않았다.
