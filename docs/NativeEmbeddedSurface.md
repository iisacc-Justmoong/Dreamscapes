# 네이티브 뷰의 전환 표면

Dreamscapes의 LVUI 화면을 기존 제품 창에 단계적으로 연결할 때 공통 iiGUI 표면을
사용한다. 각 화면은 자신이 소유한 뷰모델과 위젯 생성 함수를 주입하며, 표면은
좌표·표시·호스트 수명만 관리한다. 이미지처럼 작업자가 필요한 화면은 제한된
iiSDK 런타임을 요청할 수 있다. 단순한 화면은 별도 작업자를 만들지 않는다.

표면은 소유 스레드에서만 생성·이동·숨김·종료한다. 부모 창이 먼저 닫히더라도
열려 있는 작업을 비동기적으로 정리하고, 자원과 호스트를 순서대로 해제한 뒤에만
종료 콜백을 전달한다. 창을 사용할 수 없거나 위젯 생성에 실패하면 호출자는 기존
화면을 계속 표시할 수 있다. 이 경계는 전환용 호스트이므로 이것만으로 전체 QML
진입점이나 모든 화면이 제거되는 것은 아니다.
기존 창에 모달이나 팝업이 뒤늦게 붙는 경우에도 기존 화면으로 제어를 돌린다.
이를 위해 창의 오버레이 자식 변경만 관찰하며 가상 목록의 모든 행 변경을 감시하지
않는다.

검사는 숨긴 운영체제 테스트 창에서 공통 표면과 작업자 유무, 창 우선 종료를
확인한다. 실제 제품 실행이나 생성 추론을 대신하지 않는다.

네이티브 캔버스 미리보기를 포함하는 빌드는 iiSharedCanvas가 요구하는
`iiImageCodec::to_srgb`의 헤더와 실제 라이브러리를 구성 단계에서 함께 검사한다.
같은 버전 번호의 오래된 SDK가 선택되어 링크 단계에서 실패하는 것을 방지한다.
