# Compact editor tool panels

The reference is [Dreamscapes Figma 772:80714](https://www.figma.com/design/bn8O4AHKr1X9DWnhR1TgEy/Dreamscapes?node-id=772-80714). The live atlas contains Camera/Photo, historical Asset, File, Background, Audio, Canvas, Generative, Layers, Select, Retouch, Fill and Brush. Asset remains excluded from the runtime toolbar under the existing product contract.

Audio, Canvas, Generative, Select, Retouch, Fill and Brush now use `EditorCompactPanel.qml` on desktop and mobile. Their former unified forms and text mode pickers are replaced by the source's 30px icon selectors, trailing Reset icon, current-view heading, parameter icons and ordered state-specific rows. Generative has two groups of four selectors. The 38 explicitly drawn state copies and their 167 parameter/action occurrences are recorded independently in `fixtures/CompactPanelsFigma.json`. Lasso remains available as the fifth Select tab; its four existing controls use the same compact layout because the atlas only draws the other four Select copies.

`EditorCompactDefinitions.js` contains presentation metadata referencing existing stable field IDs. It changes no persisted parameter ID or generation operation. Expand maps to the existing Outpaint operation. Selecting a configuration view preserves all other values and drafts; switching tools, closing/reopening the panel and moving between desktop/mobile retain the selected view. Reset retains the view and resets the tool values using the existing tool contract. Live generation model choices still come from the runtime model list.

The same installed LVRS controls and the original 134 icon assets are used. Buttons keep fixed Default or Borderless roles across selection, hover and press. The reference's 432px frame has 398px of content; narrower panels adapt input widths and option rows so fields stay in bounds. Dimension fields sit side by side. Preview rows remain passive with their existing trailing disclosure. Actions use a 22px Default icon button with a small adjacent caption.

All parameters present in the Figma state remain visible. Existing engine capability checks disable unavailable controls and explain why through accessibility descriptions. Unsupported markers, custom/top anchor modes, flat/custom brush tips, Color/Soft light brush blends and generative upscale methods are not mapped to unrelated existing operations. Existing values outside the displayed design choices remain in the draft. The Content-aware action is a real Preview fill: it runs the existing repair operation on a detached in-memory document and renders the result. Closing that preview changes neither pixels nor selection/history. Its Apply repair action uses the existing document transaction and supports Undo. Opening Face Refine displays its disabled parameters and consumes pointer presses without drawing the previous repair mask. This UI alignment does not add ICC conversion, conditioning engines, face refinement or new brush rendering modes.

The Layers presenter also uses the atlas's four original navigation icons, trailing Reset and current-view icon/title. Layer rows use the compact 17px spacing, action tiles use 22px icons, and Delete retains its fixed Destructive role from the atlas. The delete glyph is the original light Figma SVG (#CED0D6), with unchanged path geometry, so it remains visible on the destructive surface. Its real document hierarchy, selected-layer properties, adjustments, measured histogram and color sampling remain document-backed. Camera/Photo, File and Background retain their dedicated state presenters and actual document/device values; the atlas's example filenames, media counts and thumbnails are not copied into runtime data.

`Dreamscapes.EditorCompactPanels` checks the independent Figma row order and geometry, all views, fixed button roles, capability disabling, draft retention, Reset, shared desktop/mobile routing and narrow layouts. Existing editor, native canvas and dedicated presenter suites cover their retained behavior. Local captures and source comparison evidence are saved under `build/tool-panels-772-80714-20261016/`.
